# 本地指纹浏览器

Windows本地浏览器管理器。当前安装使用独立本地内核、目录加密和环境连续性检查；日常运行不依赖原厂客户端或原厂在线签名服务。

**v0.2.0便携测试版：支持21个已适配精确内核的来源导入和本地创建、持久批量任务、原生会话恢复及SSH代理。其他20个内核继续使用严格检查，未扩大148以外的设备差异放行范围。**

本轮本机97项自检、21核84次IP信息页替换，以及两台新Windows各94项标准合成验收均已通过。指定真实窗口的独立副本在本机完成60秒保持及两轮服务器认证。GitHub代理链路不稳定，真实账号的跨设备两小时验收未完成；本版按用户决定先作为预发布便携包，供实体电脑测试，不将网络诊断或合成验收冒充真实账号长测。实际范围见[发版与跨设备验收](docs/发版与跨设备验收.md)。

干净发行包不包含任何账号窗口、代理凭据或已有密钥。首次启动生成当前目录专属的新密钥并显示空列表；可本地新建窗口，或从本机比特来源导入。用已有资料测试时，请先按[便携升级与实体机测试](docs/便携升级与实体机测试.md)复制资料，再首次启动新版。

本版支持单个/批量创建（每批最多1000个），可选21个已适配精确内核，配置和签名在本地生成。云端同步不参与创建；默认固定指纹并保留登录资料。功能对应与实测边界见[本地窗口创建](docs/本地窗口创建.md)。

## 运行

双击根目录的 **启动本地浏览器.cmd**。完整复制程序目录前，正常关闭所有浏览器窗口和管理器；目标平台为Windows 10/11 x64、系统.NET Framework 4.7.2或更新版本。请保留`app/data`及其中的目录密钥，以及`runtime`和内核目录。

## 目录

```text
app/                  产品源码和静态界面
  ui/                 无构建步骤的HTML/CSS/JavaScript
  data/               私有资料、加密目录库、密钥和恢复备份（不清理）
  local-engines/      当前独立内核及完整性清单（不清理）
  engines/            原始内核库存、兼容迁移来源（保留）
runtime/              随包Python、WebView2及首次导入所需的Node转换器
tools/                维护命令，不作为产品启动入口
tests/                当前项目级契约和界面状态测试
docs/                 当前架构和开发文档
analysis/             历史研究、专项回归、报告与源码回滚快照
```

## 检查

在程序目录打开PowerShell：

```powershell
.\runtime\python\python.exe tools\check_project.py
.\runtime\python\python.exe tools\inspect_installation.py
```

第一条只检查源码和隔离测试夹具，不启动账号窗口或使用真实代理。第二条只读检查当前安装的资料、加密、基线及随包文件；数据库仅连接临时副本。运行中、占用不明或读取时变化的资料会跳过验证，整体不会报告完整通过。检查报告写入`analysis/reports`。

当前不支持Firefox、未知内核构建和v20/App-Bound资料；真实第二台电脑及平台风控不能由本机模拟测试代替。目录加密的钥匙随目录携带，持有完整目录的人具有使用资料的能力。

Windows内核有路径长度限制。程序会检查整个内核资源树，必要时自动使用Windows为同一目录提供的短路径启动，保存的资料路径与指纹不变；只有磁盘未提供可用短路径或资源仍过深时，才提示移动完整程序目录，不会把仅启动进程当成窗口可用。
