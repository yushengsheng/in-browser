# 本地指纹浏览器

Windows本地浏览器管理器。当前安装使用独立本地内核、目录加密和环境连续性检查；日常运行不依赖原厂客户端或原厂在线签名服务。

**v0.2.8便携版：支持完整新版包覆盖原目录后正常启动自动更新；修复代理短路径识别、扩展复制恢复和界面状态问题。保留同步、新建、资料保护及会话恢复功能；Python、Node、WebView2和原始148内核随包提供。**

本版变更与实际验证范围见[版本说明](docs/版本说明-v0.2.8.md)。实体第二台电脑及真实账号长期状态仍未完成验收，本机合成样本不能替代这些验证。

0.2.1源码已通过本机97项自检；全新密钥148合成窗口在本机换目录后，两轮重开保留五类存储、两个标签及导航。此前0.2.0完成21核84次IP信息页替换、两台新Windows各94项标准合成验收，以及指定真实副本的本机60秒保持和两轮服务器认证。这些历史验收没有在本次重新执行。真实账号的跨设备两小时验收仍未完成，本版供实体电脑测试，不将合成验收冒充真实账号长测。实际范围见[深度对齐复核](docs/深度对齐复核-20261110.md)及[发版与跨设备验收](docs/发版与跨设备验收.md)。

干净发行包不包含任何账号窗口、代理凭据或已有密钥。首次启动生成当前目录专属的新密钥并显示空列表；可本地新建窗口，或从本机比特来源导入。已有资料位于完整便携目录内时，换机直接带走该完整目录；程序升级和历史长路径目录整理见[便携升级与实体机测试](docs/便携升级与实体机测试.md)。

从v0.2.7升级：正常关闭全部浏览器窗口和管理器，将完整v0.2.8包的内容覆盖到原目录，再双击原目录的 **启动本地浏览器.cmd**。入口会自动校验并更新程序，资料及已有内核保持原位，不需要另外运行更新或迁移脚本。支持来源、空间需求和中断恢复见[原地更新](docs/原地更新.md)。旧版v0.2.7 ZIP保留原样。

本版支持单个/批量创建（每批最多1000个），可选21个已适配精确内核，配置和签名在本地生成。云端同步不参与创建；默认固定指纹并保留登录资料。功能对应与实测边界见[本地窗口创建](docs/本地窗口创建.md)。

## 运行

含已有资料的完整便携目录同时携带运行环境、内核、配置、资料及密钥。正常关闭窗口和管理器后，将整个目录带到另一台Windows 10/11 x64电脑或移动盘，直接双击包内 **启动本地浏览器.cmd**；新电脑无需已有资料、比特客户端或另装Python、Node、WebView2，不需要先执行迁移工具。不要在ZIP内部直接运行。系统基础要求仍为Windows自带的.NET Framework 4.7.2或更新版本。

启动入口只使用包内运行环境，缺件时拒绝借用系统Python或系统WebView2。旧的完整迁移和手动更新入口已停用。带资料的完整便携目录与不含资料的干净升级ZIP是不同交付物；不能将空程序包当作已有账号的便携包。旧长目录和缺件问题须在交付前处理，资源管理器提示长路径时不能跳过。

同一父目录下可以放置A、B两个完整子目录。每份使用自己的`app/data`和内核，分别维护窗口及进程；同步功能仍会定位本机比特资料，由用户选择后复制进当前包。来源不是两份程序共用的运行资料。通用流程和验证边界见[便携兼容与双包隔离](docs/便携兼容与双包隔离.md)。

## 目录

```text
.program-packages/     新版便携包的完整程序载荷；正常启动依赖当前载荷，需随完整目录保留
app/                  产品源码和静态界面
  ui/                 无构建步骤的HTML/CSS/JavaScript
  data/               私有资料、加密目录库、密钥和恢复备份（不清理）
  local-engines/      当前独立内核及完整性清单（不清理）
  engines/            原始内核库存、兼容迁移来源（保留）
runtime/              随包Python、WebView2及首次导入所需的Node转换器
tools/                维护命令，不作为产品启动入口
tests/                当前项目级契约和界面状态测试
docs/                 当前架构和开发文档
analysis/             历史研究、专项回归、报告与源码回滚快照
```

## 检查

在程序目录打开PowerShell：

```powershell
.\runtime\python\python.exe tools\check_project.py
.\runtime\python\python.exe tools\inspect_installation.py
```

第一条只检查源码和隔离测试夹具，不启动账号窗口或使用真实代理。第二条只读检查当前安装的资料、加密、基线及随包文件；数据库仅连接临时副本。运行中、占用不明或读取时变化的资料会跳过验证，整体不会报告完整通过。检查报告写入`analysis/reports`。

当前不支持Firefox、未知内核构建和v20/App-Bound资料；真实第二台电脑及平台风控不能由本机模拟测试代替。目录加密的钥匙随目录携带，持有完整目录的人具有使用资料的能力。

Windows内核有路径长度限制。程序会检查整个内核资源树，必要时自动使用Windows为同一目录提供的短路径启动，保存的资料路径与指纹不变；只有磁盘未提供可用短路径或资源仍过深时，才提示移动完整程序目录，不会把仅启动进程当成窗口可用。
