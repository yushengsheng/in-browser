# 0.2.3便携测试版

正常使用只需双击完整目录内的 **启动本地浏览器.cmd**。Python、Node、WebView2及原始148内核随程序提供，不需要在新电脑安装这些运行环境，也不需要先运行迁移工具。已有资料、配置、密钥和已部署内核随完整目录一起携带。

本次修正：启动器只用随包Python；管理器固定使用随包WebView2及本目录的管理器缓存，防止外部环境变量重定向；配置转换只用随包Node。缺件时明确失败，不借用其他安装。构建前检查四项运行程序，ZIP名称保留完整版本号。

公开程序ZIP按用户要求不包含现有账号资料。它与已经带资料的完整便携目录不同，不会从新电脑寻找旧账号。完整目录换机前正常关闭窗口及管理器，复制全部文件到合理短目录后直接启动；不要在ZIP内部运行。

本版保留0.2.2的短独立内核布局、完整身份及整树校验。历史旧长目录仍可能使资源管理器在复制阶段报错，须在原机准备完整的整理副本；新机首次启动不能补回跳过的文件。当前维护复制工具保留整树，不自动删旧内核。便携不代表支持任意深目录。

目标系统为Windows 10/11 x64，系统需自带.NET Framework 4.7.2或更新版本。程序环境随包不等于携带整个Windows系统；代理可达性和平台登录凭证是否仍有效也由目标环境和平台决定。本机合成验证不能代替第二台实体电脑或真实移动盘实测。
