# v0.2.9 版本说明

本版沿用 v0.2.8 的干净 Windows x64 便携包和覆盖更新布局。

## 主要变化

- 新增批量导入代理：一次粘贴后，按文本顺序分配给已选窗口的本地序号升序列表。支持无认证、账号密码、附带日期及多种常见分隔符；整批校验通过后一次保存，失败保持原配置。
- 编辑代理、指纹配置或归档时，若无法确认窗口资料已关闭，则停止操作。损坏的旧代理端口可通过输入有效新代理修复。
- 更新恢复收尾遇到 Windows 短暂文件占用时进行有限重试，每次重新核对事务归属；持续占用和已有备份仍按原规则保护。
- 发布前核对随包 Python 依赖的固定版本，支持从官方 v0.2.7、v0.2.8 发行包覆盖升级。

## 全部内核适配

全部 21 个已支持精确内核构建的适配代码、创建资源、签名处理、环境连续性及完整性校验规则随程序完整更新。发行包提供原始 148 内核，其余内核继续从已支持的本机来源按需部署；没有把全部内核程序重复装入 ZIP。

已有独立内核与窗口资料按既有更新流程保留。未知构建不会仅因版本号相近而自动获得支持。

## 安装与升级

首次安装：完整解压到新目录，双击根目录的“启动本地浏览器.cmd”。

从官方 v0.2.7 或 v0.2.8 升级：正常关闭全部浏览器窗口和管理器，将新版 ZIP 的全部内容覆盖到原目录，再正常启动。保留整个目录中的 `.program-packages`；资料、密钥及已有内核保持原位。干净发行包不包含账号窗口、代理凭据或已有密钥。

## 实际验证范围

2026-11-23 的最终程序源码通过 138 项默认检查，0 失败、0 跳过，包含 1,080 个 Python 单元测试和 158 项前端测试；真实 WebView2 批量代理场景 43 项通过，带互联网来源标记的随包程序集也完成空管理器显示、初始化和正常退出。原安装 7 个窗口的只读前后对比一致。

本次发布重新逐文件核对上述验收快照与当前源码；除版本号、README 和本版本说明外，程序、工具、测试及适配资源保持已验收字节。随包运行环境沿用官方 v0.2.8 的 2,162 个文件，逐文件与旧版正式 ZIP 一致，19 个固定依赖元数据匹配。发布归档另作逐文件内容、完整清单和源码一致性核验。

这些结果来自本机隔离合成验收及字节绑定核验；本次没有重新执行全部 21 内核的真实开窗、实体第二台电脑或真实账号长期登录验收。
