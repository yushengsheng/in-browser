# v0.2.7 便携测试版

程序原生标题显示“本地指纹浏览器 v0.2.7”，版本读取自包内`VERSION`。同一目录重复启动仍只前置已有管理器，包括尚未重启的旧标题窗口；不同目录继续相互隔离。

## 变更

- 修复Windows路径查询与文件句柄查询对可执行后缀权限的不同表示，避免将未变化文件误报为复制失败。保留文件身份、时间、只读属性和完整内容校验。
- 修复窗口已达到系统允许尺寸后，重复排列被误报失败的问题。只有当前系统尺寸限制能准确解释实际结果时才算完成；无响应、归属变化及查询失败仍保守拒绝。
- 包含列表搜索防抖、排序器复用、有界状态与签名展示缓存、进程属性读取优化，以及WAL连接设置优化。正式打开、保存、签名校验及资料保护逻辑保留。
- 增加真实界面和回环代理验收入口；补齐其发行夹具及异常退出收尾。

## 已执行的本机回归

- 21个支持内核分别创建、登记46项环境基线、两次实际打开/关闭并删除，另验证批量创建密钥和噪声独立。
- 真实WebView验证搜索、筛选、排序、分页选择、编辑、分组、回收站、导出、开关窗口、导入部分失败、取消及中断继续。
- 两项此前失败来源在独立副本中完成正式导入，原来源和原目录数据未改变。
- 124/148实际浏览器验证认证HTTP/SOCKS5、信息页及标签恢复、失败不直连、批量开关和窗口排列。
- 六个边界内核验证原生Cookie导入及两次重开；合成资料验证持久/会话Cookie、LocalStorage、SessionStorage、IndexedDB、标签导航、双副本隔离和正式目录迁移。

发布前另对本次准确源码和随包运行环境执行默认自检、完整ZIP校验及干净管理器启动验收。合成来源、回环服务及模拟旧DPAPI失效仅证明对应本机流程，不代表真实网站登录或实体跨机验收。

## 已知限制

142内核在一次本机环境验证页导航中失败，程序拒绝真实开窗并保留资料。随后同一资料6次重开、18次并行空白探针及新建142完整重测均通过；首次偶发原因仍未确定，不能称为已修复。

实体Win10/Win11新电脑和真实账号长时间验收仍由用户完成，不将历史Server验证替代为本轮桌面验收，不保证所有网站登录或风控结果。本版按用户要求公开发布，继续标记为预发布测试版。

## 使用和资料边界

新用户将ZIP完整解压到可写目录，双击`启动本地浏览器.cmd`。包内含固定运行环境与原始148内核；其他已支持内核沿对应本机来源导入部署。新电脑没有这些其他内核时，不能仅凭选项列表认为它们已经随包提供。

干净发行包不含账号、代理凭据、已有目录密钥或绑定的独立内核。已有资料升级前先正常关闭并备份完整原目录，按[便携升级与实体机测试](便携升级与实体机测试.md)操作；不要用空程序包替代资料备份，也不要删除原`app/data`或`app/local-engines`。程序重启后显示新版本标题。
