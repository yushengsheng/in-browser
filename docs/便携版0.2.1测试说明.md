# 0.2.1新电脑测试说明

这是不带账号、代理或旧密钥的干净Windows 10/11 x64程序包。包含随包Python、Node、WebView2和原始148内核；不要在ZIP内直接运行。

1. 把ZIP完整解压到一个新的空文件夹，优先使用较浅目录，双击根目录“启动本地浏览器.cmd”。首次启动显示空列表，可测试新建148窗口。
2. 若需测试原有账号状态，先不要启动空包。正常关闭旧程序的窗口和管理器，按[便携升级与实体机测试](便携升级与实体机测试.md)将旧目录的`app/data`、`app/local-engines`、`app/engines`复制到新版，使用新版自带`runtime`。
3. 将准备好的整个新版目录复制到新电脑；同一账号的原电脑窗口保持关闭。核对账号自然登录、原标签及正常关闭后重开，代理需在新电脑可用。

本版修复同指纹批量随机字体不一致/重试重抽，补齐旧位置Cookie资料密钥认证，并修复干净电脑首次创建时未选用随包148库存的问题。首次部署优先完整校验随包库存；库存存在但损坏时拒绝，不借用另一份库存掩盖错误。没有更改旧窗口指纹或放宽环境、代理门禁；148以外的内核仍可能因新设备差异拒开。

先保留旧目录备份。完整迁移目录含账号秘密，只在自己的设备保存；本次提供的干净ZIP不包含这些资料。新电脑真实账号长期保持仍是待验证项，不能由本机测试或配置一致承诺。
