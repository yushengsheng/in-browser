# v0.2.12 版本说明

本版集中处理来源预览补全、代理运行后的重复启动，以及所选窗口缓存清理，保留原有导入、代理和资料保护规则。

## 本版变化

- 来源预览自动分批补全名称、编号和备注。单项读取失败仍继续后面的来源，保留勾选、搜索和分页状态；不改变正式导入流程、并发或确认有效期。
- 修复代理运行后遗留Python代码缓存导致再次启动完整性检查失败的问题。代理子进程隔离旧缓存读取并停止生成新缓存；启动和更新只兼容已认证源码对应的普通缓存文件，未知文件、链接和源码摘要仍严格校验。
- 主列表新增所选窗口缓存清理。运行中或占用状态不明时跳过，只清理固定缓存目录中的普通文件，保留账号、Cookie、密码、网页会话、标签恢复和网站持久存储。

## 发行与升级

沿用v0.2.8的便携包布局：全部21个已支持精确内核的适配代码、资源和校验规则随包，原始148内核及Python、Node、WebView2随包，其余内核按需部署。公开ZIP为空资料包，不包含用户资料、准备缓存或私有部署内核。

升级兼容清单保留官方v0.2.7至v0.2.10，并补入已经核验的v0.2.11发行清单。取得本版正式发行包后，先正常关闭全部窗口和管理器，再将完整包覆盖到原目录并运行“启动本地浏览器.cmd”。资料及已有内核保持原位；详细步骤和恢复边界见[原地更新](原地更新.md)。

## 验证状态与限制

本轮在Windows 11（26100）完成以下验证：

- 完整默认自检143项通过、0失败、0跳过；独立代码审查未发现需阻止发行的可操作问题。
- 真实148内核使用全新合成资料完成新建、导入、运行中跳过缓存清理、闭窗清理、未选窗口保持及重开。Cookie、五类网页存储、两个标签、导航和原环境基线保持；非缓存文件逐文件摘要保持。
- 同目录双包隔离、整体目录搬迁及每窗两轮重开通过。旧DPAPI包装失效为模拟条件，没有更换实体电脑或实际Windows用户。
- 66项真实管理器及启动升级检查通过：正常CMD首启/二启、v0.2.11覆盖后首启/二启、默认确认退出、旧worker实际产生的5个运行时缓存兼容及合成资料保持。
- HTTP和SOCKS5各有完整的定向开窗、公开页面加载、已开只前置、正常关闭和worker退出证据，未产生新字节码缓存。公开源码与完整候选包的秘密扫描、21核适配资源及运行环境固定依赖核对通过。

联网验收不能称为全部线路健康：四条授权测试线路在不同时点出现认证拒绝或超时；两次较早的开窗拒绝因当时诊断不足，原因仍未知。后续成功没有回填这些失败。最后一个最多四次的诊断批次在第1次因私有页面观察器收到CDP错误而停止，其正式开窗已成功，其余3次未执行；不能把该观察失败说成产品开窗失败，也不能推定具体原因。私有脚本此前对网页必须含h1元素的假设已被同地址、正确标题、完整加载及HTTP200的现场证据否定。所有原失败记录均保留，未修改产品门禁来迁就测试。

发行封装只更新本说明和必要封装元数据；最终包须与上述已验候选的功能源码、运行环境及原始内核逐字节一致，并再次核验完整发行/运行环境清单和源码对应关系。

全部内核适配随包不等于21个内核均已在本版、不同设备和所有网站逐项实测。同机合成资料、代理检测或目录搬迁不能代替第二台实体电脑与真实账号的长期登录验收。历史偶发来源稳定性失败的全部根因仍未确认；本版不宣称解决所有导入问题或保证网站永久保持登录。
