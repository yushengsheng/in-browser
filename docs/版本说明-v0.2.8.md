# v0.2.8 版本说明

本版保留已有同步、新建、窗口管理、代理、资料加密及会话恢复功能。

## 变更

- 完整新版便携包覆盖原目录后，正常启动自动校验并事务更新；资料、密钥和已部署内核留在原位。移除旧手动更新和完整迁移工具。
- 导入选择页支持最多10项批量搜索。
- 补齐首次导入Cookie及原生标签组恢复边界、扩展完整性和来源快照一致性检查；已有窗口不重复重放来源快照。
- 修复Windows短路径启动时代理误判浏览器已退出，以及扩展复制中断后共享暂存阻断后续导入。
- 修复设置迟到读取覆盖新编辑、分组改名或删除后筛选失效、超长分组名归属丢失和行内焦点导致运行状态筛选延迟刷新。
- 补齐发行白名单中的CommonJS测试文件，保证公开源码和便携包的默认自检完整。
- 修复嵌入式Python维护命令的模块定位，以及Windows系统虚拟进程相对路径导致首次安装被误判为程序占用的问题。

## 更新方式

正常关闭本程序的全部浏览器窗口和管理器，将完整新版ZIP解压覆盖原v0.2.7目录，再双击原目录的`启动本地浏览器.cmd`。新安装直接解压到新目录后启动。不要只复制程序文件，也不要在ZIP内部运行。

## 验证边界

本机合成样本用于验证功能和资料保持；不代表所有网站的登录永不过期。尚无第二台实体电脑，本轮不声称完成跨机或真实账号长期验收。服务端撤销、到期和额外验证仍由网站决定。支持已核实的21个精确内核及v10资料，未知构建和v20/App-Bound资料仍拒绝。
